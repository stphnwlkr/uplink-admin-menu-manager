# Security policy

## Supported versions

Security fixes are applied to the latest release of Uplink Admin Menu Manager.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Send the details to `iam@stphnwlkr.co`, including the affected version, reproduction steps, and the possible impact.

You should receive an acknowledgment within seven days. Confirmed issues will be investigated and addressed before public disclosure.
